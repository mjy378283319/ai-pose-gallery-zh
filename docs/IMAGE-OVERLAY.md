# 素材生图（选图 + 文字 → 生成新图）

入口：左侧导航「工作台 → 素材生图」，地址 `/overlay`。

## 这是做什么的

选一张素材图作为**参考**，写一句你想要画面的**描述**，交给 B 房 ComfyUI 生成一张**新图**。
不是把文字画在图上——文字是用来告诉 AI 你想把参考图改造成什么样。

## 使用顺序

1. **选参考图**（三选一）
   - 点「我的素材」里任意一张图（人像 / 服装 / 姿势图都可以）
   - 或「上传本地图片」
   - 或「用上一张生成图」继续迭代
2. **写描述**：越具体越好，例如
   `把这张图里的人换成白色连衣裙，站在樱花树下，阳光柔和，写实摄影风格，半身构图`
3. 点「生成新图」，右侧实时显示进度和结果。

## 为什么要单独做这个入口

应用原有的「AI 角色合成台」也支持参考图 + 文字生成，但入口藏得深，而且：
- 「我的素材」里的图点「加入配方」进的是**附加参考图（extraImages）**通道；
- 当前稳定的 Z-Image 单图工作流只认**人像参考槽位**，不读附加图通道。

所以本页把选中的图直接设为人像参考槽位，绕开这个坑，选图即可用。

## 边界与前提

- 生成器必须是**本地 ComfyUI（B 房）**。页面顶部会提示并支持一键切换。
- 工作流用内置的「Z-Image INT8 单图参考」稳定预设；参考图 + 文字生成，显存 8GB 可跑。
- 生成走 B 房间本机显卡、浏览器回环地址，单位网络看不到图片和提示词内容。
