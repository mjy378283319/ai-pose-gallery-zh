# 素材生图（方案 B：多图文字化 + 单图参考）

入口：左侧导航「工作台 → 素材生图」，地址 `/overlay`。

## 背景：为什么这样做

Z-Image-Turbo 是**文生图**模型，多张参考图走 `TextEncodeZImageOmni` 是实验节点，
实测三图同输会出棋盘格。8GB 卡也带不动真正支持多图融合的 Qwen-Image-Edit（20B）。

所以采用**方案 B**：把人像/服装/姿势三张图的意图**全部写成文字**，
只用**一张图**作为视觉参考——文字负责信息，参考图负责画面依据，绕开三图参考的坑。

## 使用顺序

1. **加入文字**：在「我的素材」里，对每张图点「+文字」按钮，把该图存的描述加进提示词。
   人像、服装、姿势三张可以全加，文字会按顺序汇总到右侧描述框。
2. **设参考图**：点其中一张图的**缩略图**设为视觉参考（建议选人像图）。
   也可以不选图 → 纯文字生成。
3. **调整描述**：描述框可自由增删。建议顺序：人像特征 → 服装 → 姿势动作 → 场景/光线/风格。
4. **生成**：点「文字 + 参考图生成」。

文字描述存得好不好，直接决定效果。可在「我的素材」里编辑每张图的文字（点铅笔）。

## 前提

- 生成器必须是**本地 ComfyUI（B 房）**，页面顶部可一键切换。
- 工作流用内置「Z-Image INT8 单图参考」稳定预设，832×1216，8GB 显存可跑。
