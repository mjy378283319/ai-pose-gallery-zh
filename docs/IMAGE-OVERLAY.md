# 图片加字（一次性工具）

入口：左侧导航「工作台 → 图片加字」，地址 `/overlay`。

## 能做什么

- 给 **AI 合成台生成的图片**、**本地上传的图片**、**「我的素材」里已有的图片** 添加文字。
- 调字号、字体、颜色、描边、底框透明度、对齐方式和位置；支持换行与拖动定位。
- 导出 **原图尺寸 PNG**，文件名自动追加 `_加字`。

## 边界（方案 A）

- 纯前端 Canvas 合成：不调用 ComfyUI，不上传图片，不消耗显存。
- 不保存“文字工程”：刷新页面后文字参数恢复默认；需要修改时重新编辑并导出。
- 生成图片仍走「AI 角色合成台」；生成后点侧栏「图片加字」，再点「用最近生成图」即可接着加字。

## 使用顺序

1. 打开 `/overlay`。
2. 选择图片：上传本地图片 / 去生成图片 / 用最近生成图 / 我的素材。
3. 输入文字，设置样式。
4. 拖动预览或选位置预设。
5. 点「导出 PNG」。

## 实现位置

- 页面：`src/routes/overlay.tsx`
- 路由：`src/routeTree.gen.ts`
- 导航：`src/components/layout/nav.ts`
